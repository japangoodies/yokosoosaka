Import from Facebook

Extract product posts from Facebook into the admin panel.

Step 1: Install the Importer button
  1. You have Tampermonkey installed ✓
  2. Click the green button below → Tampermonkey will ask to install
  3. Click Install in Tampermonkey's tab
  4. Go to any Facebook post → a blue 📥 Import button appears at bottom-right
  5. Click it → data copied to clipboard ✓
